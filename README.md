# 洛克王国：世界 - 家园精灵交配排布助手

## 问题背景

在游戏《洛克王国：世界》的家园系统中，玩家可以摆放精灵小窝并让精灵入住。当两个小窝中住有异性精灵（雌性和雄性）时，如果它们之间的曼哈顿距离小于等于 5，这两只精灵就有机会交配产下精灵蛋。

**生蛋机制说明：**
- 生蛋的两只精灵在下次生蛋前会有一段随机时间的冷却
- 蛋如果不被玩家取走会一直占用雌性精灵的小窝
- 即使冷却结束，如果蛋未被取走，该雌性精灵也无法继续生蛋

## 核心问题

**目标**：在家园中摆放精灵小窝，使得异性精灵之间的有效生蛋配对数最大化。

### 数学抽象

这个问题可以抽象为以下数学模型：

- **小窝**：在平面坐标系中，每个小窝占据一个 2×2 的方形区域（边与坐标轴对齐）
- **性别类型**：
  - Type 0 (♀)：雌性精灵的小窝
  - Type 1 (♂)：雄性精灵的小窝
- **约束条件**：
  - 小窝之间不能重叠（切比雪夫距离必须 ≥ 2）
  - 所有小窝的顶点坐标为整数
- **连接规则**：当两个小窝中心的曼哈顿距离 ≤ 5 时，认为它们可以建立有效配对
- **优化目标**：最大化 Type 0 与 Type 1 之间的配对连接数

## 基本假设：为什么选择最大化连接数

本项目选择**最大化异性精灵之间的配对连接数**作为优化目标，基于以下假设和分析：

### 1. 生蛋效率的核心因素

在生蛋机制中，生蛋效率取决于：
- **配对机会**：更多的有效配对意味着更多的潜在生蛋组合
- **冷却时间**：生蛋冷却结束后，如果蛋被及时取走，雌性可以立即进入下一轮配对
- **蛋的数量**：更多的配对组合意味着在单位时间内产出更多蛋的机会

### 2. 为什么连接数比度数分布更重要

理论上，如果蛋的取用是完全即时的，那么：
- **总连接数最大化**可以直接转化为最大的生蛋吞吐量
- 每只精灵与更多异性建立连接，就意味着有更多的"备选"配对机会
- 当某一对精灵处于冷却期时，更多的连接意味着可以切换到其他配对

### 3. 实际游戏中的考量

在实际游戏中：
- 玩家需要定期上线取蛋才能让雌性继续生蛋
- 如果连接数足够密集，即使部分雌性因为蛋未取走而离线，其他配对仍然可以正常工作
- 因此，整体连接密度越高，系统的"冗余度"和"容错性"越好

## 关于"蛋组"的分析

### 什么是蛋组

蛋组是精灵在性别之外的另一个属性。每只精灵属于特定的蛋组，**如果两个精灵属于不同蛋组，则无法建立配对连接生蛋**。

### 问题：考虑蛋组后最优方案是否会发生变化？

**猜想**：在当前游戏设定下，最优排布方案**几乎不需要改变**。

### 分析论证

#### 当前游戏约束

- 家园中小窝的最大数量约为 **10 个**
- 在此范围内，求解器通常能找到接近**全连接**的排布方案

#### 关键观察

假设有 n 个小窝，k 只雌性，m 只雄性：

1. **理论最大连接数**：k × m（所有异性之间都建立连接）

2. **求解器能力**：对于 n ≤ 10 的规模，求解器通常能达到 90% 以上的达成率，在很多情况下甚至可以达到 100% 全连接

3. **蛋组限制的影响**：
   - 假设某只精灵因为蛋组限制只能与部分异性配对
   - 但由于整体连接密集，限制某一对连接不会显著影响总体连接数
   - 例如：如果有 5 雌 5 雄，理论最大 25 条连接
   - 即使某只精灵因为蛋组只能连接 3 只异性而非 5 只，整体连接数可能从 25 降为 23，仍然是非常高的密度

#### 结论

由于在小规模（n ≤ 10）的情况下：
- 求解器能够实现接近或达到全连接的密度
- 蛋组限制只是从"全连接"变为"接近全连接"
- 排布的几何形状基本保持最优或接近最优

因此，**无论蛋组如何分布，当前的最优排布方案几乎不需要改变**。玩家可以放心地使用本工具计算出的排布方案，再根据实际蛋组情况微调精灵入住即可。

## 使用方法

### 输入参数

1. **小窝总数**：家园中计划摆放的精灵小窝数量（2-10）
2. **雌性精灵(♀)**：入住雌性精灵的数量
3. **雄性精灵(♂)**：自动计算（总数 - 雌性）

### 操作说明

**电脑端**：
- 点击计算后，查看可视化排布方案
- 可以手动拖拽微调排布，工具会实时显示新的配对数

**移动端**：
- 点击小窝选中
- 直接拖拽小窝到新位置
- 重叠位置会被阻止

### 结果解读

- **有效配对数**：在排布方案中，曼哈顿距离 ≤ 5 的异性小窝对数
- **配对达成率**：实际配对数 / 理论最大配对数（雌性数 × 雄性数）
- **绿色连线**：可视化区域内的有效配对连接

## 技术实现

本工具使用以下算法求解最优排布：

1. **多模式初始化**：尝试网格、交错行、双列等多种初始排布模式
2. **模拟退火优化**：通过温度调度避免陷入局部最优
3. **局部搜索精修**：在解空间中进行精细调整
4. **混合策略**：结合单点移动、类型交换、随机扰动等多种邻域操作
